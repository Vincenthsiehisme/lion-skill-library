# 案例篩選規則

> 此文件在 Phase 2–3 案例篩選執行前讀取。
> 包含：案例必備條件、不優先選擇的情境、Shortlist 評估標準、視角組合判斷補充準則、搜尋來源優先順序。

---

## 必備條件

優先選擇符合以下條件的案例：
- 近期（原則上近 2 年內）
- 台灣市場優先，若需國際對照則明確標注
- 具一定聲量或市場存在感
- 有足夠大的 IMC 規模 / 預算感
- 不以得獎為首要標準
- 不是已被大量寫成教材的教科書案例
- 不過度依賴代理商官網已寫好的 case study
- 有足夠公開資料可支撐深拆
- 可以支撐至少 7 頁以上的策略拆解
- 產業可混合，但避免過度集中在同一代理商或同一類型

---

## 不優先選擇

主動排除以下案例：
- 只因得獎而有名，但策略材料很薄
- 聲量高但缺少真實問題可拆
- 只有執行亮點、缺少 tension 的案例
- 明顯已被寫爛、很難再提出新觀點的案例
- 資料來源高度依賴單一次級媒體

---

## Shortlist 評估標準（每個候選案例必須回答）

> **前置退出條款**：若使用者在 Phase 1 Intake 階段已明確帶著一個成形假設來「找佐證」或「找反例」（例如：「我覺得我們應該做 X，幫我找案例證明這樣是對的」），AI 應主動提案退出本 skill，建議改走 critical-reviewer（批判性審查）或 prd-writer（問題定義階段探索）。本 skill 的價值是「橫向比較三個案例萃取策略 insight」，不是「為單一假設背書」。

| 評估問題 | 說明 |
|---------|------|
| 它在解什麼真正問題？ | 不是品牌想說什麼，而是市場 / 消費者端的真實問題 |
| 它有沒有 tension / insight 可拆？ | 有沒有值得深挖的矛盾或反直覺之處 |
| 它的 IMC / system 是否夠大？ | 接觸點是否足夠多元，能撐起 System 頁 |
| 資料是否足夠？ | 能否找到官方、主流媒體等一手資料 |
| 能否撐到足夠深度？ | 7 頁深度結構（problem / tension / reframe / system / why it lands / what to steal）每頁都能寫出有料的策略判斷 |
| 它是不是太過教科書？ | 有沒有留下新鮮判讀空間 |

**全部通過才列入 shortlist。**  
有疑慮的案例可列為「備選」，說明疑慮，交使用者判斷。

---

## 搜尋來源優先順序

廣搜候選案例時，依以下順序取用來源：

1. **品牌官網、新聞稿**（最高信度，第一手）
2. **主流財經 / 行銷媒體**（經濟日報、商業周刊、Adage、Campaign 等）
3. **業界媒體**（行銷人、動腦、The Drum 等）
4. **社群聲量**（作為佐證，不作主要來源）

越靠後的來源，越需要交叉驗證，不能單獨引用作為事實依據。

---

## 來源驗證規則

- 所有連結先驗證是否可正常開啟
- 優先使用官方來源（品牌官網、新聞稿）
- 主流媒體 > 次級媒體 > 行業媒體 > 不穩定來源
- 不能把不穩定資訊寫成既定事實
- 事實與判讀必須清楚分開標注
- 若引用圖片、廣告素材或截圖（例如品牌廣告畫面、產品照片、活動視覺），必須在來源附錄標注素材來源（品牌方 / 媒體 / 截圖網站 + URL）
- 最終輸出附 source appendix（含上一條提及的素材來源條目，與文字來源合併呈現即可，不另列分區）
