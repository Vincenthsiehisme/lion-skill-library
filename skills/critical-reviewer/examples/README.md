# Examples

這個目錄存放完整的審查輸出範例，供 Claude 在 Phase 4 需要對照格式時讀取。

## 使用時機

只有在 `../references/06-output-templates.md` 的格式說明不夠清楚時才讀取，正常審查流程不需要載入。

## 範例清單

| 檔案 | 情境 | 召集顧問 | 特點 |
|------|------|---------|------|
| `full-example-travel-product.md` | 旅遊產品分類系統概念驗證 | 使用者研究員＋風險顧問 | 包含外部校準、模擬獨立調查、召集紀錄、獨立收斂 |

## 範例結構說明

每個範例展示完整流程：
1. **背景假設**：萃取自 session 的事實背景，不等待確認。
2. **快速掃描**：文件類型判斷、框架缺口診斷與顧問召集決定。
3. **顧問召集紀錄**：標示召集、未召集、召集但不展開的原因。
4. **顧問模擬獨立調查**：各顧問的外部校準與框架分析。
5. **交叉比對整合**：獨立收斂、單一發現、顧問張力的三層結構。

## 新增範例的規範

新範例必須包含：
- `**外部校準**` 欄位，並誠實標示搜尋發現、未執行原因或待查證假設。若寫搜尋發現，必須列出 Search query、Source / title、Date、Evidence role、Finding。
- `（模擬獨立調查）` 標示在顧問名稱後。
- `顧問召集紀錄`，說明未召集或不展開的原因。
- 整合段使用 `[獨立收斂] / [單一發現] / [顧問之間的張力]` 三層結構。
- 若沒有真正獨立收斂，必須寫「無」，不得硬湊。

注意：範例不得示範無來源的「搜尋發現」。若範例沒有實際搜尋來源，必須改寫為「外部搜尋未執行」與「待查證假設」。
